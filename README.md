# TechFlow Dashboard

Projeto do Checkpoint 5 - FrontEnd Design.

## Integrantes
- Bruno Muzzi
- Daniel Lopes.

## Tecnologias
- HTML5
- Tailwind CSS via CDN
- CSS
- JavaScript puro
- localStorage

## Como executar
1. Extraia os arquivos do projeto.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` com a extensão Live Server ou diretamente no navegador.
4. É necessária conexão com a internet para carregar o Tailwind CSS pelo CDN.

## Recursos
- Layout responsivo para celular, tablet e desktop.
- Sidebar com menu mobile.
- Quatro cards de indicadores.
- Seis cards de projetos com CSS Grid.
- Pesquisa e filtro de projetos.
- Formulário de cadastro com validação visual.
- Menu do usuário.
- Temas Light, Dark e System com preferência no localStorage.
- Efeitos de hover, focus, active, disabled e transições.
